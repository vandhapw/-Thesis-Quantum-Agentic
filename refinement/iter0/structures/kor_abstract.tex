산업 4.0의 등장은 제조업을 사이버-물리 시스템으로 변모시켰으며, 예기치 않은 설비 정지는 심각한 경제적 손실을 초래한다. 그럼에도 불구하고 예지보전 연구는 여전히 단편적이다. 이상 탐지, 잔여수명 예측, 보전 일정 계획은 서로 분리된 문제로 다루어지고 있으며, 정적 모델은 센서 드리프트로 인해 성능이 저하되고, 조합적 일정 계획의 복잡성은 기계 수에 따라 지수적으로 증가한다. 본 학위논문은 이러한 문제를 단일 폐쇄루프 시스템 내에서 해결하기 위해 제안된 3계층 통합 아키텍처인 QASAMAP(Quantum-Agentic Smart Manufacturing Anomaly detection and Predictive Maintenance) 프레임워크를 제안한다.

제1계층은 50대의 기계에서 69일간 수집된 100,000건의 데이터셋에 대한 시공간 예측 및 지도학습을 수행한다. 상호상관 시차 그래프(50개 노드, 538개 엣지)를 구축한 Temporal Graph Convolutional Network(T-GCN)는 5개 센서 채널 전반에 걸쳐 평균 R\textsuperscript{2} = 0.7702를 달성하여, 독립 LSTM(0.6853, +12.4\%) 및 하이브리드 LSTM-GCN(0.7134, +8.0\%) 베이스라인을 능가한다. 또한 6개 예측 대상에 대해 5개 지도학습 알고리즘의 포괄적 벤치마크를 수행하여, 이상 탐지 F1 = 0.999, 고장 유형 분류 F1 = 0.880, 보전 필요성 예측 F1 = 0.872, 잔여수명 회귀 R\textsuperscript{2} = 0.189의 기준 성능을 확립하였다.

제2계층은 Ollama Cloud API를 통해 \texttt{MultiAgentOrchestrator}가 조정하는 9개의 LLM 기반 에이전트로 구성된 다중 에이전트 에이전틱 AI 시스템을 구현한다. 이 시스템은 센서 데이터 수집부터 보전 작업 배포까지 완전한 예지보전 의사결정 주기를 자율적으로 관리하며, 맥락적 기억, 휴리스틱 오버라이드 중재, 지속적 학습을 통합한다. 사후 감사 정직 평가 결과, 분리된 25대 기계 테스트 분할에서 F1 = 0.00, 전체 50대 데이터셋에서 F1 = 0.33(정밀도 = 1.00, 재현율 = 0.20), 평균 예측 지연 시간 5,771.8초를 보고하였다. 270회 호출에 대한 LLM 벤치마크는 JSON 구문 분석률 66.7--82.2\% 및 추론 품질 71.7--84.8\%를 보여준다.

제3계층은 미래 양자 하드웨어 이전을 위해 양자 대응물의 수학적 구조를 보존하는 양자-영감적 고전 휴리스틱을 추가한다. Pauli-Z 다중 센서 위험 인코딩, QUBO 형식화된 우선순위 순위 검색, QAOA 형식화된 그래프 일정 계획으로 구성되며, 휴리스틱 오버라이드 메커니즘은 고전적 위험 점수가 LOW로 표시될 때에도 위험 신호를 보유한 기계를 능동 검사로 에스컬레이션한다. 실험 평가에서 이 메커니즘은 고전 임계값이 소극적으로 모니터링할 7대 기계 중 5대에 대한 실행 가능한 결정을 트리거한다. \textbf{알고리즘 공개:} 모든 ``양자'' 구성요소는 표준 CPU에서 고전 휴리스틱으로 구현되며, 양자 프로세서는 사용되지 않는다. 따라서 실험 결과는 고전 휴리스틱 성능을 반영한다.

QASAMAP은 시공간 예측, 다중 작업 지도학습, 양자-영감적 휴리스틱 최적화, 그리고 에이전틱 오케스트레이션을 단일 아키텍처 내에서 통합함으로써 지능형 제조 보전을 발전시키고, 향후 연구를 위한 정직하고 재현 가능한 벤치마크를 제공한다.
