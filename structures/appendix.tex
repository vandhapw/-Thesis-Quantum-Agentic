\chapter{Pre-Registered Experimental Protocols}

The complete pre-registered protocol document for the V2 3-layer experiments
(\texttt{PHASE1\_PROTOCOL\_V2\_ALIGNED\_3LAYER.md}) is preserved in the thesis
repository at \url{https://github.com/vandhapw/-Thesis-Quantum-Agentic} under
\texttt{phase\_docs/}. The protocol specifies hypotheses, sample sizes,
statistical tests, and halt rules \emph{before} execution for the three V2
experiments: E-L2 (Layer~2 multi-tier detection validation), E-L3A
(Layer~3 static scheduling solver comparison), and E-L3B (Layer~3 dynamic
rolling-horizon real-time feasibility).

\chapter{Pre-Registration Deviation Documents}

Three pre-registered methodology deviations were documented during the E-L2
validation:

\begin{itemize}
    \item \textbf{Deviation \#001}: prompt template revision (V1 sensor-only
          vague tier definitions $\to$ V2 decision-tree pseudocode with
          numeric thresholds and worked examples). Triggered by V1
          $\kappa = 0.362$ STOP result.
    \item \textbf{Deviation \#002}: drop \texttt{qwen3.5:cloud} from the
          ensemble due to 53\% empty-content technical incompatibility.
          Triggered by V2 smoke test parse-rate inspection.
    \item \textbf{Deviation \#003}: expand the LLM input set to the realistic
          deployment information set (sensor readings + failure-type
          signature + RUL forecast + anomaly flag + downtime risk +
          maintenance flag). Triggered by V2 worse-than-V1 result and
          information-asymmetry root cause analysis.
\end{itemize}

The full deviation documents (\texttt{PRE\_REG\_DEVIATION\_001.md},
\texttt{PRE\_REG\_DEVIATION\_002.md}, \texttt{PRE\_REG\_DEVIATION\_003.md})
are preserved in the thesis repository under
\texttt{experiments/E-L2\_agentic\_validation/}.

\chapter{Reproducibility Artefacts}

All experimental artefacts (per-run CSVs, raw LLM responses, statistical
reports with what-can/cannot-be-claimed sections, solver implementations,
prompt templates) are preserved at the thesis repository under
\texttt{experiments/} for the V2 experiments (E-L2 V1/V2/V3, E-L3A, E-L3B)
and under \texttt{experiments/} for the archived V1 experiments (E1, E3, E5,
E6, E-Q1, E-Q3) which were superseded by V2 but retained as historical
record. Reproduction requires Python 3.10+, standard scientific stack
(NumPy, SciPy, scikit-learn, pandas), \texttt{qiskit-aer},
\texttt{dwave-neal}, and an Ollama Cloud API key for Layer~2 LLM ensemble
calls (the LLM cache provided in the repo enables fully cached replay
without re-incurring API cost).
