## 2. STUDY PURPOSE & RATIONALE

### 2.1 Background

Predictive maintenance (PdM) systems in smart manufacturing increasingly use AI-generated alerts to inform human operator decisions. Two prevalent alert formats exist:

1. **Machine-learning (ML) format:** numeric anomaly score + top contributing features
2. **Hybrid agentic-AI format:** ML score + natural-language explanation + recommended action + estimated urgency, generated by Large Language Model (LLM) agents

Despite increasing deployment of LLM-augmented PdM systems in industry [1-3], **no published empirical study has measured the effect of alert format on operator decision quality, time, or confidence** in a controlled within-subject design. This gap motivates the present study.

### 2.2 Research questions

- **RQ1:** Does hybrid agentic-AI alert format improve operator decision accuracy compared to ML-only format?
- **RQ2:** Does hybrid agentic-AI alert format reduce operator decision time?
- **RQ3:** Does hybrid agentic-AI alert format increase operator confidence?
- **RQ4:** What is operator-perceived trust and willingness to use each format?

### 2.3 Significance

This study provides empirical evidence necessary to validate claims in the parent thesis, *"Quantum-Agentic Smart Manufacturing for Anomaly Detection and Predictive Maintenance"* (QASAMAP), and informs design of future operator-facing PdM alert systems.

### 2.4 References supporting study rationale

[1] Palma & Cecchi (2025). *Large Language Models for Predictive Maintenance in the Leather Tanning Industry: Multimodal Anomaly Detection in Compressors.* MDPI Electronics 14(10):2061.
[2] MDPI Computers (2025). *AI Agent-Enabled Predictive Maintenance: Conceptual Proposal and Basic Framework.* 14(8):329.
[3] Tandfonline (2025). *A review of explainable artificial intelligence in smart manufacturing.*

- **Target N:** 8-10 participants
- **Minimum acceptable N:** 8 (for analysis with Bayesian credible intervals)
- **Power justification:**
  - With paired-design effect size *d* = 0.6 (medium-large, expected from prior LLM-vs-ML literature [Wu et al. AutoGen COLM 2024; Brown et al. NeurIPS 2020]), α = 0.05, target power = 0.80, ideal N = 24.
  - Realistic N = 8-10 yields power ≈ 0.50-0.65; results will be reported with 95% confidence intervals AND Bayesian credible intervals to honestly represent uncertainty.
  - Study will be framed as **preliminary evidence** and recommendation for follow-up larger study made explicit in thesis discussion.

## 4. STUDY PROCEDURES

### 4.1 Overall design

**Within-subject A/B comparison.** Each participant evaluates 20 maintenance scenarios using two alert formats (Condition A: ML-only; Condition B: hybrid agentic-AI). Order of conditions counterbalanced across participants and scenarios.

### 4.2 Detailed procedure

**Step 1 — Consent (5 min)**
- Participant accesses study URL (Streamlit app)
- Reads participant information sheet
- Indicates consent via checkbox; cannot proceed without consent

**Step 2 — Demographic questionnaire (3 min)**
- Years of maintenance/PdM experience
- Job role (categorical: technician / engineer / researcher / student / other)
- Familiarity with AI tools (1-5 Likert)
- Native language

**Step 3 — Tutorial (5 min)**
- Two practice scenarios (one per condition format)
- Feedback on correct action provided after each tutorial

**Step 4 — Main study (20 min)**
- 20 scenarios presented in randomized order
- 10 scenarios with Condition A (ML-only) format
- 10 scenarios with Condition B (Hybrid Agentic) format
- Counterbalanced via Latin-square randomization
- For each scenario, participant:
  - Reads alert content
  - Selects recommended action from 4-option dropdown:
    1. Monitor only
    2. Schedule inspection
    3. Schedule maintenance
    4. Immediate shutdown
  - Rates confidence in decision (1-10 slider)
  - Time-to-decision measured automatically

**Step 5 — Post-study questionnaire (5 min)**
- Perceived usefulness of each format (5-point Likert)
- Trust in each format (1-10 scale)
- Open-ended: "What did you like / dislike about each format?"

**Total session duration:** ~30-40 minutes

### 4.3 Materials

**Scenario database:** 20 maintenance scenarios derived from previously-collected synthetic streaming data (no real industrial data; no proprietary information). Scenarios balanced for:
- 10 true anomalies (across 5 failure modes: bearing wear, overheating, electrical, vibration, pressure drop)
- 10 normal operations (some near-threshold to test discrimination)

**Software:** Streamlit web application (open-source). Hosted on local PKNU server or Streamlit Community Cloud. Participants access via web browser; no installation required.

### 4.4 Data collection

For each (participant, scenario) cell, the following are recorded:
- Participant ID (anonymous, randomly-generated UUID)
- Scenario ID
- Condition (A or B)
- Action selected (1-4)
- Confidence rating (1-10)
- Decision time (seconds, automatic)
- Timestamp

**Demographic and post-study data** (anonymized):
- Years of experience
- Job role
- Familiarity with AI
- Native language
- Likert ratings on usefulness/trust
- Open-ended text responses

**Storage:** All data stored in encrypted JSON file at `experiments/E4_user_study/data/` on PI's institutional Google Drive (PKNU institutional account). Access restricted to PI and faculty advisor.

## 11. APPENDIX D — DATA ANALYSIS PLAN (PRE-REGISTRATION)

### Primary hypotheses

**H1a:** Decision accuracy is higher with Hybrid Agentic (Condition B) than ML-only (Condition A).
- Test: paired t-test (or Wilcoxon signed-rank if non-normal)
- Effect size: Cohen's d_z
- Significance: α = 0.05 (two-tailed)

**H1b:** Decision time is shorter with Hybrid Agentic.
- Test: paired t-test on log-transformed time
- Effect size: Cohen's d_z

**H1c:** Confidence rating is higher with Hybrid Agentic.
- Test: Wilcoxon signed-rank (Likert data)
- Effect size: r (rank biserial correlation)

### Secondary analyses

**Mixed-effects model** with rater as random intercept:
```
outcome ~ Condition + scenario_difficulty + (1 | rater_id)
```
Rationale: account for between-rater variability.

**Cohen's κ** for inter-rater agreement on ground truth (between PI and second reviewer).

**Cronbach's α** for confidence scale (target ≥ 0.7).

### Bayesian sensitivity analysis

Given expected low N (8-10), a Bayesian paired-comparison model with weakly informative priors will be reported alongside frequentist tests:
- Prior on Cohen's d ~ Normal(0, 1) (weakly informative)
- Posterior 95% credible interval reported

### Multiple comparisons

3 primary tests (H1a, H1b, H1c) → Bonferroni-corrected α = 0.05/3 = 0.017 OR Benjamini-Hochberg FDR at q=0.05 (will report both).

### Reporting

All results reported with:
- Descriptive statistics (mean, SD)
- Test statistic + df + raw p-value + adjusted p-value
- Effect size + 95% CI
- Bayesian credible interval
